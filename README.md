 Telegram Stats Bot — Спираль 1
Бот для анализа личного Telegram-чата с поддержкой RAG (Retrieval-Augmented Generation) и внешних инструментов.
Работает полностью локально, без отправки данных в облако.

✨ Функции
📈 Статистика чата
/stats — показывает общее количество сообщений и ваших личных сообщений.
🔍 RAG по вашим данным
Задавайте вопросы по вашему чату:
«Что я писал о парсерах?»
«Какие темы обсуждались в октябре?»
Бот отвечает на русском языке и указывает источник из вашего чата.

курс доллара → актуальный курс USD/RUB
погода в Москве → текущая температура

▶️ Запуск
1. Подготовка
Убедитесь, что установлены:

-Ollama (с GPU-поддержкой для RTX 4060)
-Python 3.10+
2. Установка зависимостей
bash:

1# Клонируйте или перейдите в папку проекта
2cd ~/projects/telegram-stats-bot
3
4# Создайте и активируйте виртуальное окружение
5python3 -m venv .venv
6source .venv/bin/activate
7
8# Установите зависимости
9pip install -r requirements.txt

3. Настройка
Создайте файл .env:

1TELEGRAM_BOT_TOKEN=ваш_токен_от_@BotFather
2OLLAMA_MODEL=llama3-local

Поместите ваш чат в формате JSON:

1data/sample_chat.json
"Формат: массив объектов с полем "text". "

4. Запуск
bash:

1python3 -m src.bot.main

## 🧪 Тестирование

Тесты с моками внешних API (курс, погода) временно отложены из-за сложности корректного мокирования асинхронного клиента `httpx`.  
Планируется реализация в **Спирали 2** с использованием библиотеки [`respx`](https://github.com/lundberg/respx).
